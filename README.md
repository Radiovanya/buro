# CRM «Бюро строительства»

Интерактивный MVP системы управления снабжением строительных проектов. Центральная сущность — счёт, который связывает заявку, проект, поставщика, бюджет, оплату и доставку.

## Демо

[Открыть демонстрацию](https://radiovanya.github.io/buro/)

В демо доступны:

- дашборд руководителя с рабочей очередью;
- реестр и карточка счёта с независимыми статусами согласования, оплаты и доставки;
- согласование счёта и предупреждение о превышении бюджета;
- создание заявки и черновика счёта;
- проекты, бюджет, платежи, доставки и контрагенты;
- адаптивная мобильная навигация.

Данные демонстрационные и хранятся только в состоянии браузера.

## Локальный запуск

Требуется Node.js 22+.

```bash
npm install
npm run dev
```

Для обновления статической версии GitHub Pages:

```bash
npm run build:pages
```

## Стек

React 19, TypeScript, Next.js/vinext. Папка `docs/` содержит готовую статическую сборку для GitHub Pages.
